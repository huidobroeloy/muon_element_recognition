# Muonic X-ray element recognition for Roman coinage (v2)

A physics-validated simulation + neural-network pipeline for **non-destructive
elemental analysis with negative muons** (muonic X-ray emission spectroscopy,
µXES / MIXE). It is built around the Roman-coin work carried out at the
ISIS RIKEN-RAL muon facility by the Oxford / Warwick / ISIS group:

* G. A. Green, K. Ishida, B. V. Hampshire, K. Butcher, A. M. Pollard,
  A. D. Hillier, *Understanding Roman gold coinage inside out*,
  J. Archaeol. Sci. **134** (2021) 105470 (Oxford School of Archaeology /
  Ashmolean; open copy on ORA).
* G. A. Green, K. Ishida, A. D. Hillier, *Negative muons reveal the economic
  chaos of Rome's AD 68/9 Civil Wars*, Archaeol. Anthropol. Sci. **14** (2022) 165.
* B. V. Hampshire, K. Butcher, K. Ishida, G. Green, D. M. Paul, A. D. Hillier,
  *Using negative muons as a probe for depth profiling silver Roman coinage*,
  Heritage **2** (2019) 400-407.

Every number taken from these and other papers lives in
[`src/literature.py`](src/literature.py) with its source.

## Results

See [`results/`](results) (regenerated by the commands below):

**Physics** (`physics_validation.png`): 19 independent measured muonic lines
reproduced with median error 0.17 keV (0.026 %), max 1.1 keV; published
implantation depths reproduced within their errors.

**Network, held-out simulated test set** (4 000 spectra, `evaluate.py`):

| metric | value |
|---|---|
| element presence (>= 1 wt%), micro-F1 | **0.989** |
| exact element set correct | 94.9 % (aurei 97 %, asses 99 %) |
| composition error, elements >= 5 wt% (MAE) | **1.30 wt%** (aurei 0.22, denarii 0.8-1.1) |
| detection at 1-2 wt% | Ag 0.92, Cu 0.95, Sn 0.99, Zn 1.00, Hg 0.92, Pb 0.79 |
| false-positive rate | <= 0.5 % |
| 1-sigma uncertainty coverage | 0.84 (slightly conservative) |

Per-element F1 is 0.85-1.00 for the 22 elements with enough examples; rare
trace elements (P, Co, Se, Cd, Ba, Pt, Bi) almost never reach 1 wt% in the
simulated population and are **not** learned (F1 ~ 0) — they need a
dedicated trace-element training population.

**Roman-coin benchmarks vs. the published peak-fit method** (`case_studies.py`):

* *A. Clean Au-Ag-Cu alloys, fixed instrument, both calibrated on the same
  standards:* the published peak fit is more accurate
  (MAE Au/Ag/Cu 0.22/0.65/0.58 wt%) than the network (0.58/1.25/0.77). When the
  alloy system is known and the instrument is calibrated, the 4-peak fit is
  hard to beat, and this repository does not claim otherwise.
* *B. Six published gold coins:* the peak fit reproduces the XRF assays within
  ~0.3 wt%; the network finds the right elements but over-estimates Ag by
  2-3 wt% in debased coins (e.g. Otho: 14.1 vs 10.9 wt%). At 18 MeV/c the
  network is more stable where the peak fit becomes unstable (Tiberius Cu
  0.59 ± 0.91 wt%).
* *C. Julia Domna depth profile:* both recover the published profile (bulk
  49 at% Ag, layer ~195 µm). Network: bulk 50.1 ± 1.3 at%, layer 197 ± 10 µm;
  peak fit: 47.5 ± 0.6 at%, 186 ± 4 µm. For this gradual profile the
  forward-model inversion and the published "mean depth" fit agree. Adding
  momenta (17-45 MeV/c, 11 settings) cuts the bulk uncertainty ~3×
  (1.3 → 0.4 at%). This is an actionable recommendation for beam-time planning.

**Bottom line.** Use the network for what the published analysis does not
do: blind identification of all elements present (corrosion, solder, Pb/Sn/Zn
additions, Hg gilding, plating), a calibrated detection probability and
uncertainty per element, and robustness when the alloy system is unknown. For
final major-element numbers in a known Au-Ag-Cu system, the standards-calibrated
peak fit (reproduced in `baseline.py`) remains the more accurate tool. The
natural next step is a hybrid: the network identifies the elements, and a
multi-line physics template fit, using every line of each identified element,
does the quantification.

## What the published analysis does, and what this repository adds

| | Published ISIS/Oxford analysis | This repository |
|---|---|---|
| Line identification | by eye / pure-element reference spectra | 1D CNN over the full low- **and** high-energy HPGe spectra, 29 elements, calibrated probabilities |
| Quantification | Gaussian fits of 2 peaks per element (Ag 4f-3d, Cu 3d-2p, Au 5g-4f) + calibration factor from a standard; binary (Ag-Cu) or ternary (Au-Ag-Cu) alloy assumed | full-composition estimate (wt%, metal basis) with a per-element uncertainty, optionally corrected with the same standards |
| Interferences | Pb (collimator) and Al (packet) peaks "ignored" | modelled explicitly: air N/O, Al packet, collimator Pb, <sup>196</sup>Pt capture γ at 333/356 keV (between the Cu lines!), Ge(n,n'), 511 keV, <sup>40</sup>K, <sup>208</sup>Tl, escape peaks, Compton edges |
| Depth profile | point estimates placed at the SRIM mean depth, exponential fitted through them | same **plus** a forward-model inversion that averages the profile over the full muon stopping distribution (momentum bite, straggling, air + packet), and a momentum-set design study |
| Detection limit | "approximately 1 %" | measured as a function of concentration for every element (see `detection_limit.png`) |

The published peak-fit method is re-implemented faithfully in
[`src/baseline.py`](src/baseline.py) so the two approaches are compared on
identical spectra.

## Pipeline

```
src/literature.py      all literature data (energies, depths, coin assays, standards)
src/config.py          element table: Z, isotope, rms charge radius, I-value; detector grids
src/physics.py         radial Dirac solver (Fermi nucleus + Uehling VP) and muonic cascade
src/transport.py       muon stopping (Bethe, calibrated), layered targets, photon attenuation
src/materials.py       Roman coin families (aurei, denarii, antoniniani, fourrees, ...) + general heritage materials
src/simulate.py        forward model -> expected spectra in LE (20-1000 keV) and HE (0.1-8 MeV) HPGe detectors
src/dataset.py         pre-generation into memmaps; Poisson re-noising at random exposure on every read
src/model.py           MuonNet (two-branch residual CNN with energy-coordinate channels, 3 heads)
src/train.py           multitask training, early selection, per-element threshold tuning
src/optimize.py        Optuna hyper-parameter search (TPE + median pruning)
src/evaluate.py        held-out test metrics, detection limits, figures
src/baseline.py        re-implementation of the published peak-fit analysis
src/case_studies.py    Roman-coin literature replicas (A: NN vs peak fit, B: gold coins, C: Julia Domna)
src/inference.py       Analyzer class for new (e.g. real) spectra + calibration with standards
src/validate_physics.py  figure/JSON comparing physics with measurements
```

### 1. Physics (`physics.py`) — validated against measurements

v1 used the point-nucleus Sommerfeld formula with an empirical K-line scale
factor and hand-set intensities for six lines. v2 solves the **radial Dirac
equation numerically** for every (n, κ) level up to n = 10 of each nucleus
(vectorised RK4 shooting with node counting), for a muon with the
muon-nucleus reduced mass in the potential of a **two-parameter Fermi charge
distribution** (rms radii from Angeli & Marinova 2013) plus the **Uehling
vacuum-polarisation potential** folded over that distribution — the physics of
MuDirac (Sturniolo & Hillier 2021). A single residual shift of the 1s level
(nuclear polarisation + higher-order QED), interpolated in Z from six measured
2p<sub>3/2</sub>-1s energies (Ti, Fe, Pd, Nd, Au, Pb), is the only fitted
quantity. Solver self-test: agrees with the analytic point-Dirac energies to
10<sup>-10</sup> keV.

**Independent validation** (19 measured lines never used in any fit; full
table from `python physics.py`, figure `results/physics_validation.png`):
median |model − measured| = **0.17 keV (0.026 %)**, worst 1.1 keV
(Pd 4d-2p). Including the very lines the coin studies quantify with:

| line | measured (keV) | this model | v1 model |
|---|---|---|---|
| Ag 4f<sub>7/2</sub>-3d<sub>5/2</sub> | 304.5 (Hampshire 2019) | 304.78 | not in v1 line list |
| Ag 4f<sub>5/2</sub>-3d<sub>3/2</sub> | 308.2 | 308.45 | — |
| Cu 3d<sub>5/2</sub>-2p<sub>3/2</sub> | 330.6 | 330.86 | "a few %" |
| Cu 3d<sub>3/2</sub>-2p<sub>1/2</sub> | 336.4 | 336.52 | — |
| Sn 4f-3d | 345.254 / 349.975 | 345.265 / 349.976 | — |
| Pb 5g-4f | 431.328 / 437.749 | 431.44 / 437.84 | — |
| Pd 3d-2p (Saito et al. 2022) | 833.4 / 863.8 | 832.86 / 863.07 | — |
| Pb 2p<sub>1/2</sub>-1s | 5778.9 | 5778.53 | — |
| Au 5g-4f (Green 2021: "400-410 keV") | — | 400.12 / 405.62 | — |

Line **intensities** come from a muonic cascade started at n = 14 (Green et al.
2021) with a modified-statistical l-distribution, E1 radiative rates
(hydrogenic dipole matrix elements, Dirac energies) competing with an Auger
channel, and 6j-symbol fine-structure splitting; 56-608 lines per element,
Kα yield 0.61/µ (C) → 0.97/µ (Pb). The two poorly-known cascade parameters are
**randomised** during training (domain randomisation), so the network cannot
over-fit an intensity model that is only approximately right.

### 2. Transport and detectors (`transport.py`, `simulate.py`)

* Bethe stopping with one global range-scale factor fitted to the published
  SRIM depths **after the 100 mm air gap and 16 µm Al packet** of the ISIS
  set-up: 13 µm vs "~10 µm" (Au, 18 MeV/c), 405 vs ~400 µm (Au, 40 MeV/c),
  387 vs 402 ± 61 µm (Julia Domna alloy, 35 MeV/c); it also gives 59 µm at
  22 MeV/c where Hampshire et al. report a surface point at 54.6 µm.
* 10 % FWHM momentum bite, 3 % straggling; muons stopping in air / packet /
  backing produce N, O, Al lines, exactly as seen in the published spectra.
* Layered objects: surface-enriched denarii (exponential profile), fourrées,
  gilding, forged plating, corrosion crusts (cuprite, atacamite, malachite,
  chlorargyrite, acanthite, cerussite, goethite) and soil.
* Self-absorption of every line from the mean stopping depth of each layer
  (Klein-Nishina + photoelectric model within 10-15 % of NIST XCOM).
* Electronic K X-rays of the (Z−1) atom, nuclear-capture γ (Ni from Cu, Pd
  from Ag, <sup>196</sup>Pt from Au, ...), detector efficiency, resolution,
  bin-integrated Gaussians, Compton continua, single/double escape peaks,
  gain/offset drift, beam and environmental background, collimator Pb, and
  occasional random unexplained peaks.

### 3. Network (`model.py`) and training

v1's CNN ended in global average pooling, which makes it translation-invariant:
it could see *that* a peak exists but not *where* — yet the energy is what
identifies an element. MuonNet adds fixed energy-coordinate channels and keeps
the spatial axis until a position-aware linear layer; the LE and HE detectors
get separate residual branches; beam momentum and count totals enter as
auxiliary inputs. Three heads per element: presence (masked BCE: 0.2-1 wt% is
an "ambiguous" band that is not penalised), composition (KL on the wt-fraction
simplex) and uncertainty (Gaussian NLL). Expected spectra are stored once and
re-noised (Poisson, random ×0.3-×3 exposure) on every read. Optuna searched
learning rate, weight decay, width, embedding/hidden sizes, dropout and loss
weights; the best trial is stored in `checkpoints/best_config.json`.

## Quick start

```bash
cd src
python -m venv ../.venv && ../.venv/Scripts/pip install -r ../requirements.txt   # Windows
python physics.py            # builds data/dirac_levels.json (~12 min once) + validation table
python validate_physics.py   # results/physics_validation.png
python simulate.py           # builds data/cascade_lines.pkl, times the simulator
python dataset.py --n 4000  --seed 202 --out ../data/val
python dataset.py --n 4000  --seed 303 --out ../data/test
python dataset.py --n 60000 --seed 101 --out ../data/train        # ~10 min on 3 cores
python optimize.py --trials 7 --epochs 3 --samples-per-epoch 4800
python train.py --config ../checkpoints/best_config.json --epochs 9 --samples-per-epoch 24000
python evaluate.py
python case_studies.py
```

Analysing a real spectrum (re-binned onto the LE/HE grids in `config.py`):

```python
from inference import Analyzer
an = Analyzer("../checkpoints/best.pt")
an.calibrate_with_standards(standard_spectra, standard_compositions)   # optional, e.g. MAC 1-3
for el, p, wt, err, present in an.report(le_counts, he_counts, momentum=35.0):
    print(el, p, wt, err, present)
```

## Limitations (read before using on real data)

* **Everything here is trained and tested on simulation.** The published raw
  spectra are not public, so the Roman-coin "replicas" reproduce the published
  compositions, depths and set-up, not the actual measured spectra. Before use
  on real data the model should be fine-tuned / checked on real standards and
  pure-element spectra from the same instrument (`Analyzer.calibrate_with_standards`
  is the minimum).
* Cascade intensities are approximate (hydrogenic dipole matrix elements, a
  one-parameter Auger model, no electron refilling) and are therefore
  randomised; energies are accurate (see validation).
* Natural isotope mixtures are represented by the most abundant isotope
  (isotope shifts matter only for K lines of heavy elements, at the keV level).
* Photon attenuation is parametric (±10-15 %); the Bethe range model is
  calibrated on three published SRIM depths (the 18 MeV/c "~0.01 mm" is
  a rounded statement).
* Muon capture between elements uses a Z-law with a small random exponent
  jitter; real alloys can deviate, which is again why calibration with
  standards is recommended.
* Pd and Nd are included only as physics validation anchors.
